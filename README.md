# Nativity for Mac, releases

Notarized DMGs of [Nativity](https://nativity.asit.space) for the Mac (macOS 26 or later, Apple Silicon). This repository holds only the downloads; the app's source is private.

Install with Homebrew:

```bash
brew tap asitkhanda/nativity-tap
brew install --cask nativity
```

Or download the latest DMG from [Releases](https://github.com/asitkhanda/nativity-macos-releases/releases).
